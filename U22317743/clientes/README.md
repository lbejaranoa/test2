
# Módulo de Gestión de Clientes

## 1. Descripción
Este módulo forma parte de una práctica colaborativa de desarrollo de software. Su objetivo es crear la estructura inicial para la gestión de clientes.

## 2. Objetivo
Diseñar una interfaz web básica que permita registrar y visualizar la información de los clientes.

## 3. Estructura del proyecto

```text
clientes/
├── index.html
├── style.css
└── README.md
```

## 4. Tecnologías utilizadas
- HTML5: estructura de la página web.
- CSS3: diseño y estilos de la interfaz.
- Git: control de versiones.
- GitHub: colaboración y almacenamiento remoto.

## 5. Funcionalidades iniciales
- Formulario para registrar clientes.
- Campos para nombre, correo electrónico y teléfono.
- Sección para visualizar la lista de clientes.

## 6. Rama de trabajo
`feature/clientes`

## 7. Equipo responsable
Equipo A
