# Sistema de Pedidos

## Descripción

Este proyecto corresponde al desarrollo colaborativo de un sistema de pedidos. 
El sistema permite gestionar información relacionada con clientes, productos y pedidos,
facilitando la organización y administración de las operaciones del negocio.

El proyecto se desarrolla utilizando Git y GitHub, aplicando un flujo de trabajo basado
en ramas para que cada integrante pueda trabajar de manera independiente y posteriormente
integrar sus cambios al repositorio principal.

## Objetivo

Desarrollar un sistema de pedidos mediante trabajo colaborativo, aplicando buenas
prácticas de control de versiones, organización del código y documentación del proyecto.

## Funcionalidades

El sistema contempla los siguientes módulos:

- Gestión de clientes.
- Gestión de productos.
- Gestión de pedidos.
