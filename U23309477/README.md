# Sistema de Pedidos - Proyecto Colaborativo

Este proyecto corresponde a la implementación de un sistema de pedidos distribuido en módulos, desarrollado como parte del trabajo colaborativo de la asignatura.

## Estructura del Proyecto

* **Documentación y README:** Integrante A
* **Módulo de Clientes:** Integrante B (`U23309477/clientes/`)
* **Módulo de Productos:** Integrante C (`U23309477/productos/`)
* **Módulo de Pedidos:** Integrante D (`U23309477/pedidos/`)

## Instrucciones de Integración
Cada módulo se ha desarrollado en su respectiva carpeta para asegurar que la rama `develop` se mantenga funcional y sin conflictos.
